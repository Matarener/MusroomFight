# Драка на (грибной) поляне

Рабочее название проекта — «Грибница». Игра для Telegram Mini App: на ферме растут кристаллы стихий, ими прокачивается отряд из девяти грибов, отряд проходит пошаговые бои в лесу.

Написана на чистом JavaScript (ES-модули) с собственным движком на Canvas 2D и собственной скелетной анимацией. Внешних библиотек в игре нет.

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
node tools/serve.mjs
```

Откройте http://localhost:5173. Сервер также пишет адрес для телефона в той же сети Wi‑Fi.

ES-модули не работают, если открыть `index.html` двойным щелчком, поэтому для разработки нужен сервер.

### Сборка в один файл

```bash
npm install      # один раз, ставит esbuild
npm run build    # → dist/index.html
```

`dist/index.html` содержит всю игру в одном файле: его можно открыть двойным щелчком или выложить на хостинг (GitHub Pages, Netlify, Vercel) и привязать к боту через BotFather.

## Структура

```
index.html            разметка интерфейса и значки (SVG-спрайт)
styles/main.css       стили интерфейса поверх игры
src/
  main.js             точка входа: собирает движок, состояние, интерфейс и сцены
  engine/             движок, ничего не знает об игре
  skeleton/           скелетная анимация, ничего не знает об игре
  game/
    data/             константы: бойцы, кристаллы, бои, данные скелета
    state.js          состояние игрока и все операции над ним
    art/              рисование текстур (один раз при запуске)
    scenes/           сцены фермы, леса и боя
    battle/rules.js   правила боя без графики
    audio/            музыка и звуки, синтезированные кодом
    settings.js       настройки игрока (качество, кадры, громкость), хранятся в браузере
    ui/               HTML-интерфейс: верхняя панель, окна, экран отряда, счётчик кадров
    router.js         переключение экранов и пауза игры
tools/                сервер для разработки и сборка
```

Зависимости идут в одну сторону: `game` → `skeleton` → `engine`. Движок и скелет можно взять в другую игру без изменений.

## Движок (`src/engine`)

| Модуль | Что делает |
|---|---|
| `Engine` | игровой цикл на `requestAnimationFrame`, сцены, ввод, размер холста, ограничение кадров, пауза |
| `Renderer` | два холста: статичный (фон, рисуется один раз) и динамичный (каждый кадр); камера вписывает экран 390×844 в любой размер |
| `TextureCache` | «запекание» текстур: каждая картинка рисуется один раз, дальше выводится одним `drawImage` |
| `Painter` | короткие команды рисования для запекания (`fillEllipse`, `fillRoundedRect`…) |
| `Scene` | объекты, зоны нажатия, твины, таймеры, тряска камеры |
| `display` | `Sprite` (текстура), `Label` (текст, перерисовывается только при смене строки) |
| `Tween` | плавное изменение свойств с функциями плавности |
| `Timer` | отложенные вызовы по игровому времени сцены |
| `Particles` | пул частиц без создания объектов во время игры |
| `PerfMonitor` | FPS, время кадра, пики, частота экрана, автоматическое снижение разрешения |
| `audio/AudioManager` | звук: рендер звуков в буферы заранее, шины музыки и звуков, громкость, плавная смена треков |
| `audio/synth` | инструменты для синтеза: маримба, колокольчик, флейта, пэд, бас, ударные, реверберация |

Правила, на которых держится производительность:

- всё неподвижное рисуется в статичный слой один раз: `sprite.setStatic()`;
- все картинки и надписи запекаются заранее, в кадре только `drawImage`;
- во время анимаций ничего не создаётся: частицы, цифры урона и надписи берутся из пулов;
- когда игру не видно (экран отряда, открытое окно), цикл стоит на паузе.

### Пример сцены

```js
import { Scene } from './engine/index.js';

export class MyScene extends Scene {
  create() {
    this.sprite('meadow', 0, 0).setStatic();
    const star = this.sprite('glint', 195, 400).setDepth(10);
    this.tweens.add({ targets: star, scale: 1.5, duration: 600, yoyo: true, repeat: -1, ease: 'sineInOut' });
    this.addZone(195, 400, 60, 60, () => this.app.toast('Нажали!'));
  }
}
// engine.register('my', MyScene); engine.show('my');
```

## Скелетная анимация (`src/skeleton`)

- `Skeleton` — данные и математика: кости, позы, ключевые кадры, плавные переходы, скины, события;
- `SkeletonSprite` — объект сцены: рисует каждую деталь одним `drawImage` в матрице кости.

```js
const hero = scene.add(new SkeletonSprite(scene.textures, MUSHROOM_SKELETON, 'mukhomor', 120, 400));
hero.play('strike', { then: 'idle' });
hero.on('event', (name) => { if (name === 'hit') { /* момент удара */ } });
```

Формат данных описан в начале `src/skeleton/Skeleton.js`, сам скелет гриба и все анимации лежат в `src/game/data/skeleton.js`. Новая анимация — это новый ключ в `animations`, новый гриб — новый скин и текстуры в `src/game/art/mushrooms.js`.

## Титульный экран

Пока игра готовит текстуры, портреты и звуки, на поляне идёт драка (`src/game/scenes/TitleScene.js`, графика — `src/game/art/titleArt.js`), а внизу идёт полоска загрузки. Кнопка «Играть» одновременно включает звук в браузере.

## Звук и музыка

Файлов со звуком нет: каждый звук и трек — функция синтеза в `src/game/audio/`. При запуске они один раз рендерятся в буферы через `OfflineAudioContext`, дальше играют готовые буферы, синтез во время игры не тратит процессор.

- `sounds.js` — звуки действий (`app.sfx('harvest')`);
- `music.js` — три зацикленных трека по 8 тактов: ферма (до мажор, маримба), лес (ля минор, флейта), бой (ре минор, барабаны и бас). Ноты записаны прямо в коде, их легко поменять.

Звук включается после первого нажатия: так требуют браузеры.

## Настройки

Шестерёнка в верхней панели и в бою. Качество (авто, высокое, среднее, низкое), ограничение кадров (нет, 60, 30), частицы, тряска экрана, счётчик кадров, громкость музыки и звуков. Всё сохраняется в браузере.

## Сюжет

Зона, где после Вспышки грибы ожили. Юный боровичок Тоша и его наставник Дед Груздь ведут отряд через девять глав леса к Вышке, где Ведьма Светлячиха копит кристаллы для Второй Вспышки. Враги — Светляки: те же грибы, но мутанты с зелёным свечением.

Катсцены лежат данными в `src/game/data/story.js`: вступление после «Играть» при первом запуске, сцены перед первым боем главы и после первой победы в ней. Реплики можно править, не трогая код. В настройках: «Смотреть вступление» и «Показывать сцены глав заново».

## Сохранение прогресса

Прогресс сохраняется сам (`src/game/save.js`): в браузере — в localStorage, внутри Telegram — ещё и в облако Telegram (CloudStorage), поэтому он переносится между устройствами. При запуске берётся более свежее из двух сохранений. Начать заново: `localStorage.removeItem('gribnica-save')` в консоли (в Telegram — ещё `Telegram.WebApp.CloudStorage.removeItem('gribnica-save')`).

## Обложка для BotFather

`assets/cover-640x360.png` — обложка Mini App (и `cover-1280x720.png` в двойном размере). Она собрана из графики игры сценой `tools/cover/`: чтобы пересоздать, запустите `node tools/serve.mjs` и выполните `cd assets && node ../tools/cover/shot.cjs` (нужен Playwright).

## Отладка

В консоли браузера доступен объект `gribnica`: `gribnica.state`, `gribnica.engine`, `gribnica.router.go('battle', 8)`. Нажатие на счётчик кадров быстро включает и выключает ограничение 60 кадров.
