# CLAUDE.md

Игра «Драка на (грибной) поляне» (рабочее название проекта — «Грибница») для Telegram Mini App.
Чистый JavaScript (ES-модули), собственный движок на Canvas 2D, собственная скелетная анимация и синтез звука.
Внешних библиотек в игре нет; esbuild нужен только для сборки в один файл.

Общение с владельцем проекта — на русском. Комментарии в коде и тексты интерфейса — тоже на русском.

## Команды

- `node tools/serve.mjs` — сервер для разработки, http://localhost:5173 (ES-модули не работают из `file://`).
- `npm install` — один раз, ставит esbuild.
- `npm run build` — сборка в `dist/index.html` (вся игра одним файлом, открывается двойным щелчком).
- Публикация: push в `main` → GitHub Actions (`.github/workflows/pages.yml`) собирает и выкладывает на GitHub Pages.

Тестов нет. Проверка — запустить игру и пройти цикл: титульный экран → ферма (сбор, посадка) → отряд (улучшение, смена тройки) → лес → бой (вручную и на «Авто ×2») → победа и поражение. В консоли браузера доступен `gribnica` (app): `gribnica.router.go('battle', 8)`, `gribnica.state`, `gribnica.engine`.

## Архитектура

Зависимости строго в одну сторону: `src/game` → `src/skeleton` → `src/engine`. Движок и скелет не знают об игре.

- `src/engine/` — `Engine` (цикл, сцены, ввод, размер, качество, лимит кадров, пауза), `Renderer` (два холста: статичный и динамичный, камера вписывает 390×844), `TextureCache` + `Painter` (запекание текстур), `Scene`, `display` (`Sprite`, `Label`), `Tween`, `Timer`, `Particles`, `PerfMonitor`, `audio/` (`AudioManager`, `synth`).
- `src/skeleton/` — `Skeleton` (позы, ключевые кадры, скины, события, переходы) и `SkeletonSprite` (отрисовка).
- `src/game/data/` — константы: `content.js` (бойцы, стихии, кристаллы, бои, цены), `skeleton.js` (скелет гриба и все анимации).
- `src/game/state.js` — `GameState`: всё состояние игрока и все операции над ним. Сцены и интерфейс меняют состояние только через его методы. Снимок для сохранения — `toSave()` / `restore()`; новые поля состояния добавлять в оба (и поднимать `SAVE_VERSION` при несовместимой смене). Для сервера заменить тела методов на запросы к API.
- `src/game/save.js` — сохранение прогресса: localStorage всегда, Telegram CloudStorage внутри Telegram; при запуске берётся более свежий снимок, запись с задержкой 1.5 с и сразу при сворачивании.
- `src/game/art/` — рисование текстур кодом (один раз при запуске). `background.js` — фоны, которые дорисовываются по ширине экрана.
- `src/game/scenes/` — `TitleScene`, `FarmScene` (+ `farm/BedView`), `ForestScene`, `BattleScene` (+ `battle/UnitView`).
- `src/game/battle/rules.js` — правила боя без графики (чистые функции).
- `src/game/audio/` — `sounds.js` (звуки), `music.js` (три трека: ферма, лес, бой).
- `src/game/ui/` — HTML-интерфейс поверх холста: HUD, окна (`Sheet`), отряд, бой, настройки, счётчик кадров, титульный экран.
- `src/game/router.js` — переключение экранов, музыка экрана, пауза игрового цикла.
- `src/game/settings.js` — настройки игрока (localStorage), применяются в `applySettings` в `main.js`.
- `src/main.js` — сборка всего и загрузка по шагам на титульном экране.

Общий контекст `app` (engine, perf, audio, settings, state, sheet, toast, ui, router, sfx) кладётся в `engine.app` и доступен сценам как `this.app`.

## Правила производительности (важно: игра должна держать 60 FPS на слабых телефонах)

- Всё неподвижное — `sprite.setStatic()`: рисуется в статичный слой один раз.
- Ничего не рисовать фигурами в кадре: только запечённые текстуры (`textures.bake`) и `drawImage`.
- Текст — через `Label` (перерисовка только при смене строки) или запечённый в текстуру.
- Во время анимаций ничего не создавать: частицы из пула, цифры урона и надписи — из заранее созданных объектов, окрашенные копии текстур (`prepareFlash`) — заранее.
- Тяжёлое (текстуры, звуки) готовить на титульном экране или заранее, а не в момент первого использования.
- Когда игру не видно (экран отряда, открытое окно), цикл на паузе (`router.syncPause`).
- Звук не синтезировать во время игры: всё рендерится в буферы через `OfflineAudioContext` (`audio.define` + `audio.load`).

## Стиль

- Графика рисуется кодом, мультяшный стиль: толстый тёмно-коричневый контур (`0x3e2512` / `0x24170f`), мягкие тени, блики.
- Размеры интерфейса внутри игры — через `calc(var(--u) * N)`, где `--u` — игровая единица в CSS-пикселях.
- Модули небольшие, с комментарием в начале о назначении. Без спагетти: данные отдельно от графики, правила отдельно от сцен.
